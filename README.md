# 🐍 Exercícios de Python

Lista de exercícios de lógica de programação resolvidos em Python, do começo do curso de Sistemas de Informação (UNEMAT).

## 📋 O que tem no `oneday.py`

1. Cálculo de idade a partir do ano de nascimento
2. Calculadora com as 4 operações (com tratamento de divisão por zero)
3. Par ou ímpar
4. Média de 3 notas com situação (aprovado / recuperação / reprovado)
5. Tabuada de 1 a 10
6. Conversor de Celsius para Fahrenheit
7. Operações com uma lista de 5 números
8. Juros simples
9. Cálculo de IMC

## 🧠 Conceitos

`input` e conversão de tipos · funções · condicionais · laços · listas · f-strings

## ▶️ Como executar

```bash
python oneday.py
```
